Which file is used when

The plugin is 45 files, but almost none of them load at once. Each phase opens a small, specific set — a procedure telling it what to do, the invariants that constrain it, and a lookup consulted per element. This is that map.

The mechanism

Everything passes through one artifact

The five analyze phases only ever write to analysis.md. Generation only ever reads it. There is no path from the browser to your source files that skips the validator — which is the entire point of splitting the two commands.

Three kinds of document

Read once, always on, or looked up

The references/ tree is split by how a document is consulted, not by topic. That is what makes the right file findable mid-run.

P1

Survey

stops at gate 1

Screenshots the page and partitions it visually before reading the DOM — that is what catches “these five controls are one filter panel”. Then measures how this app can be located at all, enumerates every element, scopes each one to the thing that owns it, and resolves every selector against the live page before a single crop is trusted. Ends by pricing the probe run.

Three of its thirteen steps exist because of failures that are otherwise invisible: the strategy probe reloads the page and compares, so a framework-minted id can’t pass as a stable hook; grounding rejects a selector that matches nothing or matches several things; and the budget turns “this will take a while” into a number you approve before it is spent.

P3

Probe

unattended · budgeted

Drains the pending queue at the tier each element was priced at. Types into inputs, selects from dropdowns, toggles checkboxes, clicks buttons — and records what actually happened. A revealed dialog simply appends more pending rows, so recursion needs no special handling. The artifact is rewritten after every element, and the run stops at 1.5× budget rather than until somebody gives up.

Two things stop a probe from looking complete while having tested nothing. The required action is checked per type — opening a dropdown and pressing Escape is honestly Clicked, and is not a probe of a dropdown. And each action is diffed against the element’s own scope, so a field that appears only after a value is chosen falls out of the comparison instead of depending on someone thinking to look for it.

P4

Classify

Matches each element against the registry, authors the locator from your conventions, re-grounds the final selector set, then cross-checks against Playwright's own and highlights it on the page. Grounding proves a selector is real and unambiguous; only looking proves it points at the control you described.

A registry match is a hypothesis about which class wraps an element — never a source of selectors. A selector copied out of the registry and into code without touching the page is the failure this phase is shaped around.
